# ប្រព័ន្ធកត់ត្រាកំណត់ហេតុប្រជុំរដ្ឋបាល (Brachum Admin) - ក្រសួងមហាផ្ទៃ

ប្រព័ន្ធជំនួយការឆ្លាតវៃក្នុងការថតសម្លេង បំប្លែងសម្លេងជាអក្សរ (Speech-to-Text) និងតាក់តែងកំណត់ហេតុកិច្ចប្រជុំរដ្ឋបាលផ្លូវការ ស្របតាមទម្រង់លិខិតបទដ្ឋានរបស់រាជរដ្ឋាភិបាលកម្ពុជា។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

1. **បច្ចេកវិទ្យា Speech-to-Text ជាភាសាខ្មែរ (Khmer Speech Recognition):**
   - ដំណើរការផ្ទាល់លើកម្មវិធីរុករក **Google Chrome** តាមរយៈ Web Speech API ដែលគាំទ្រភាសាខ្មែរ (`km-KH`) យ៉ាងរលូន។
   - គាំទ្រការចាប់ពាក្យផ្ទាល់ (Interim Streaming) និងកត់ត្រាឃ្លាពេញលេញដោយស្វ័យប្រវត្តិ។

2. **ការគ្រប់គ្រង និងបែងចែកអ្នកនិយាយ (Speaker Diarization):**
   - កំណត់ និងប្តូរឈ្មោះអ្នកនិយាយភ្លាមៗ (ឧ. *ឯកឧត្តមប្រធានអង្គប្រជុំ*, *លោកប្រធាននាយកដ្ឋាន...*)។
   - ឈ្មោះថ្មីនឹងត្រូវប្តូរជំនួសគ្រប់កន្លែងទាំងអស់នៅក្នុងអត្ថបទចម្លង។

3. **គំរូកំណត់ហេតុរដ្ឋបាលផ្លូវការ (Official Ministry Template):**
   - រៀបចំឡើងស្របតាមទម្រង់លិខិតរដ្ឋបាលរបស់ក្រសួងមហាផ្ទៃ (ព្រះរាជាណាចក្រកម្ពុជា, ជាតិ សាសនា ព្រះមហាក្សត្រ, ក្បាលលិខិតក្រសួង, អធិបតីភាព, របៀបវារៈ, ដំណើរការប្រជុំ, ការសម្រេច, តារាង Action Items, និងហត្ថលេខា)។

4. **កែសម្រួលភ្លាមៗលើក្រដាសកំណត់ហេតុ (Live Rich-Text Editing):**
   - មន្ត្រីកត់ត្រាអាចចុចវាយកែសម្រួលពាក្យពេចន៍ផ្ទាល់លើផ្ទាំងក្រដាសកំណត់ហេតុភ្លាមៗ។
   - គាំទ្រពុម្ពអក្សរខ្មែរ (Kantumruy Pro, Moul, Siemreap) និងឧបករណ៍ដិត គូសបន្ទាត់ តម្រឹមបន្ទាត់ និងបញ្ចូលតារាង។

5. **ការទាញយក និងចែករំលែក (Export & Sharing):**
   - **Microsoft Word (`.docx`):** ទាញយកជាឯកសារ Word ដែលមានក្បាលលិខិត និងតារាងត្រឹមត្រូវ ងាយស្រួលបោះពុម្ព ឬដាក់ជូនថ្នាក់ដឹកនាំពិនិត្យ។
   - **PDF / Print:** បោះពុម្ព ឬរក្សាទុកជា PDF តាមទម្រង់ក្រដាស A4។
   - **ចែករំលែកក្នុងបណ្តាញការងារ (LAN Sharing):** បង្ហាញតំណភ្ជាប់បណ្តាញ (ឧ. `http://192.168.x.x:3000`) សម្រាប់មន្ត្រីក្នុងបន្ទប់ប្រជុំ ឬក្នុងក្រសួងបើកមើល និងប្រើប្រាស់រួមគ្នាបាន។

## 🚀 របៀបបើកដំណើរការ (How to Run)

### វិធីទី១៖ ដំណើរការដោយចុច File ផ្ទាល់
គ្រាន់តែ Double-click លើឯកសារ **`start-app.bat`**
- ប្រព័ន្ធនឹងចាប់ផ្តើមដំណើរការ Server
- ហើយបើកផ្ទាំង **Google Chrome** ដោយស្វ័យប្រវត្តទៅកាន់ `http://localhost:3000`។

### វិធីទី២៖ ដំណើរការតាម Terminal / PowerShell
```bash
cd c:\BraChum
node server.js
```
រួចបើក Google Chrome ចូលទៅកាន់ `http://localhost:3000`។

## 🌐 របៀបចែករំលែកជាមួយសហការីក្នុងក្រសួង (Sharing with Colleagues)
នៅពេល Server កំពុងដំណើរការ៖
1. មើលនៅជ្រុងខាងស្តាំខាងលើនៃកម្មវិធី ត្រង់ប៊ូតុង **«ចែករំលែក: http://...:3000»**
2. ចុចលើវាដើម្បីចម្លង (Copy) តំណភ្ជាប់
3. ផ្ញើតំណភ្ជាប់នោះទៅកាន់សហការីដែលភ្ជាប់ Wi-Fi ឬបណ្តាញខ្សែតែមួយជាមួយអ្នក នោះពួកគេនឹងអាចបើកប្រើប្រាស់បានភ្លាមៗ!
